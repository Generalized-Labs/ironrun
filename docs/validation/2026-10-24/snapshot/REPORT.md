# Unpublished four-platform snapshot verification — 2026-10-24

Two sequential GoReleaser snapshot commands completed successfully against the same hash-listed, uncommitted reviewed sources. `goreleaser check` passed. Each run produced linux/amd64, linux/arm64, darwin/amd64 and darwin/arm64 binaries and archives, four SPDX 2.3 JSON SBOMs (54 package entries each), and checksums. All 18 checksum entries across the two runs were independently recomputed, including the installer in the repository.

The four binary pairs are byte-identical across these two runs. The four archive pairs are not byte-identical: their `ironrun` tar member modification times differ. Extracted member contents match for every archive; the README, license and example policy match the recorded snapshot inputs. This supports same-environment binary reproducibility, not cross-machine reproducibility or byte-identical release archives. SBOM JSON parsing/version/package presence was checked; full SPDX schema validation and dependency vulnerability analysis were not performed here.

The native linux/amd64 binary passed `version`, `--help`, `doctor --help` and `setup --help` smoke commands. The other target binaries were inspected as files but not executed. These commands do not prove a native secret-store integration, real agent-host MCP connection, or production command containment.
