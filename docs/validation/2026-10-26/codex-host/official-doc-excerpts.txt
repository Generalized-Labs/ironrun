In Local computer access with Work Cloud, the enterprise `mcp_servers` TOML requirement in Agent Security applies to local executors. Cloud containers retain Work Cloud policies. Local MCP servers and transports may not be available in the cloud; check connectivity and authentication separately.
Configure each MCP server with a `[mcp_servers.]` table in the configuration file.
- `startup_timeout_sec` (optional): Timeout (seconds) for the server to start. Default: `10`.
- `tool_timeout_sec` (optional): Timeout (seconds) for the server to run a tool. Default: `60`.
- `default_tools_approval_mode` (optional): Default approval behavior for tools from this server. Supported values are `auto`, `prompt`, `writes`, and `approve`. The `writes` mode prompts for tools that aren’t marked read-only.
- `tools..approval_mode` (optional): Per-tool approval behavior override.
The top-level `mcp_optional_startup_grace_ms` setting controls how long Codex waits for optional MCP servers when building the initial tool catalog. It defaults to `1000` milliseconds. Set it to `0` to wait for each server’s `startup_timeout_sec` instead. Required servers still use their startup timeouts.
